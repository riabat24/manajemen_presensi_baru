> **Aplikasi digital untuk mencatat presensi karyawan secara otomatis, mengelola data kehadiran, dan mempermudah proses administrasi HRD.** 🚀

---

## 🌟 Fitur Unggulan (Completed Features)

| Fitur | Deskripsi | Status |
| :--- | :--- | :---: |
| **🔐 Login & Otentikasi** | Validasi pengguna dengan role-based access (Admin & Karyawan). | ✅ |
| **🏠 Dashboard Karyawan** | Menampilkan profil, jam real-time, dan status kehadiran hari ini. | ✅ |
| **⏱ Clock-In & Clock-Out** | Pencatatan jam masuk dan keluar otomatis dari waktu sistem. | ✅ |
| **📋 Riwayat Presensi** | Log kehadiran karyawan dengan filter bulan dan rekap statistik. | ✅ |

## 🛠️ Teknologi yang Digunakan

* **Backend:** Java (JDK 17 / JDK 21) ☕
* **Frontend:** JavaFX (dengan Scene Builder untuk desain antarmuka) 🎨
* **Database:** MySQL — basis data relasional yang handal dan banyak digunakan 🗄️
* **Library (Implemented):**
  * **JDBC (MySQL Connector/J)** — menghubungkan aplikasi Java dengan database MySQL 🔌
  * **JavaFX SDK** — framework untuk membangun tampilan antarmuka pengguna
* **Library (Planned):**
  * **BCrypt** — enkripsi password akun pengguna 🔐
  * **iTextPDF** — ekspor laporan presensi ke format PDF 📄
  * **Apache POI** — ekspor laporan presensi ke format Excel (.xlsx) 📊
